# The Masterwork Forge

A single-page **Neverwinter** Masterwork guide for the Synergy guild. The Forge helps players find recipe materials by source, character class, item, or material name.

## Features

- Browse verified Masterwork recipes for all nine character classes.
- Filter by class or material source, or search for a recipe, item, or material.
- Use the shared Synergy header to move between the Guild Roster, Masterwork Forge, and Discord.
- Use the responsive page on desktop or mobile; no account or server is required.

## Open the guide

Open `index.html` in a modern web browser. Recipe information is embedded in the page, so the guide works as a standalone file. An internet connection is needed to load the optional Google Fonts; system fonts are used if they are unavailable.
