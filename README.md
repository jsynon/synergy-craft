# The Masterwork Forge

A single-page **Neverwinter** farming guide for the Synergy guild. The Forge helps players find Masterwork recipe materials by farming activity, character class, item, or material name.

## Features

- Browse farming routes including Master Demonweb Pits, Abyssal Hunt mods, Explorer Charts, and the Stronghold Vendor.
- Select a route to see the materials it supplies and the recipes that use them.
- Search recipes, materials, and sources, or filter by class.
- Use the responsive page on desktop or mobile; no account or server is required.

## Open the guide

Open `index.html` in a modern web browser. Recipe information is embedded in the page, so the guide works as a standalone file. An internet connection is needed to load the optional Google Fonts; system fonts are used if they are unavailable.
